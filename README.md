# SideTorrent

**A powerful torrent client for iPhone and iPad.**

Download, manage, and organize torrents with control over the files you keep.

</div>

## Features

- **Torrent downloads** — Add torrents from torrent files, magnet links, or supported URLs.
- **Selective file downloading** — Choose individual files and episodes instead of downloading an entire torrent.
- **Download controls** — Pause, resume, and recheck torrents whenever needed.
- **Live progress** — View download progress, transfer speeds, remaining time, peers, and seeds.
- **Flexible file priorities** — Prioritize sequential downloads or the first and last pieces when supported.
- **Torrent management** — Sort, search, filter, and organize torrents by their current state.
- **Storage options** — Choose from available storage locations and manage downloaded data.
- **File browsing** — Browse a torrent’s contents and preview or share completed files.
- **Tracker support** — View torrent trackers and use tracker-management features.
- **RSS support** — Access available RSS feed features for discovering torrents.
- **Dark and light appearance** — Use the system appearance and app accent-color options.
- **Live activity support** — See supported download activity at a glance.
- **Native iOS experience** — Designed for touch interaction on iPhone and iPad.
